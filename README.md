# Actividad: HTML semántico + validación W3C

Convertí una página hecha con `<div>` en HTML semántico y la validé sin errores ni advertencias en el Nu Html Checker (W3C).
Etiquetas usadas: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`, `<h1>`/`<h2>`, `<time>`, `<blockquote>` y `<address>`.
